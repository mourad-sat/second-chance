# منصة تدبير برنامج الفرصة الثانية

منصة عربية متجاوبة لتدبير مسار المستفيد من التسجيل الأولي إلى التتبع التربوي والمهني والإدماج في نهاية السنة.

## الوظائف المنجزة

- لوحة قيادة عربية من اليمين إلى اليسار.
- تسجيل مستفيد جديد مع التحقق من الحقول الأساسية.
- حفظ المستفيدين فعليًا في PostgreSQL عبر Prisma.
- منع تكرار رقم البطاقة الوطنية أو رقم مسار.
- عرض المستفيدين المسجلين ووضعياتهم في جدول.
- API للقراءة والتسجيل على المسار `/api/beneficiaries`.
- هيكل قابل للتوسعة للحضور والتقويم والمواكبة والإدماج.

## التقنيات

- Next.js 14
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM

## التشغيل المحلي

1. ثبّت الحزم:

```bash
npm install
```

2. أنشئ ملف البيئة:

```bash
cp .env.example .env
```

3. ضع رابط PostgreSQL الصحيح في `DATABASE_URL` داخل ملف `.env`.

4. أنشئ جداول قاعدة البيانات وعميل Prisma:

```bash
npx prisma migrate dev --name init
npx prisma generate
```

5. شغّل المنصة:

```bash
npm run dev
```

ثم افتح `http://localhost:3000`، وانتقل إلى `/beneficiaries/new` لتسجيل أول مستفيد.

## خارطة الطريق

1. استكمال ملف المستفيد وصفحة التفاصيل والتعديل.
2. القبول والاختبارات والتوجيه.
3. الحضور والغياب والتتبع التربوي.
4. التكوين المهني والمواكبة الاجتماعية.
5. التداريب والإدماج والتقارير السنوية.
