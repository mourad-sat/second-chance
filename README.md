# منصة تدبير برنامج الفرصة الثانية

منصة عربية متجاوبة لتدبير مسار المستفيد من التسجيل الأولي إلى التتبع التربوي والمهني والإدماج في نهاية السنة.

## الوظائف المنجزة

- لوحة قيادة عربية من اليمين إلى اليسار.
- تسجيل مستفيد جديد مع التحقق من الحقول الأساسية.
- حفظ المستفيدين فعليًا في PostgreSQL عبر Prisma.
- منع تكرار رقم البطاقة الوطنية أو رقم مسار.
- عرض المستفيدين المسجلين ووضعياتهم في جدول.
- ملف فردي شامل لكل مستفيد مع التعديل وتغيير الوضعية.
- توثيق الوضعية الاجتماعية والأسرية.
- توثيق المسار التربوي وأسباب الانقطاع وصعوبات التعلم.
- تسجيل التشخيص الأولي ونقاط القوة والحاجات ذات الأولوية.
- إعداد خطة مواكبة فردية وهدف دراسي أو مهني وملاحظات التتبع.
- تسجيل المقابلة الأولية ونتائج الاختبارات والميولات المهنية.
- اقتراح المسار والشعبة وتسجيل قرار لجنة القبول.
- إنشاء المجموعات حسب الموسم والمسار والشعبة.
- إسناد المستفيدين المقبولين إلى المجموعات.
- تسجيل الحضور والغياب والتأخر والغياب المبرر يوميًا.
- حفظ وقت الوصول والعذر والملاحظات.
- عرض آخر سجلات المواظبة.
- نموذج قاعدة بيانات جاهز للتقويمات والنتائج الأكاديمية.

## التقنيات

- Next.js 14
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM

## التشغيل المحلي

```bash
npm install
cp .env.example .env
```

ضع رابط PostgreSQL الصحيح في `DATABASE_URL` داخل ملف `.env`.

لإنشاء قاعدة البيانات لأول مرة:

```bash
npx prisma migrate dev --name init
npx prisma generate
```

لتطبيق التحديثات المتتابعة على مشروع موجود:

```bash
npx prisma migrate dev --name expand_beneficiary_profile
npx prisma migrate dev --name add_admission_assessment
npx prisma migrate dev --name add_attendance_and_assessments
npx prisma generate
```

ثم شغّل المنصة:

```bash
npm run dev
```

افتح `http://localhost:3000`، ثم انتقل إلى `/attendance` لتدبير المجموعات والحضور.
