# منصة تدبير برنامج الفرصة الثانية

منصة عربية متجاوبة لتدبير مسار المستفيد من التسجيل الأولي إلى التتبع التربوي والمهني والإدماج في نهاية السنة.

## النسخة الحالية

تتضمن النسخة الأولية:

- لوحة قيادة عربية من اليمين إلى اليسار.
- لائحة المستفيدين.
- استمارة تسجيل مستفيد جديد.
- نموذج أولي لقاعدة بيانات PostgreSQL باستعمال Prisma.
- هيكل قابل للتوسعة للحضور والتقويم والمواكبة والإدماج.

## التقنيات

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM

## التشغيل المحلي

```bash
npm install
cp .env.example .env
npx prisma generate
npm run dev
```

ثم افتح `http://localhost:3000`.

## خارطة الطريق

1. التسجيل والقبول وملف المستفيد.
2. الحضور والغياب والتتبع التربوي.
3. التكوين المهني والمواكبة الاجتماعية.
4. التداريب والإدماج والتقارير السنوية.
